# Jannat Collection

A premium clothing commerce website with a customer storefront, an admin dashboard, and a single Express backend.

## Stack
- React + JavaScript + CSS
- Express backend
- MongoDB ready for integration
- Paystack ready for integration
- Separate frontend URLs for customer and admin

## Project structure
- `customer` — storefront app
- `admin` — admin dashboard app
- `backend` — API and middleware server

## Install dependencies

```bash
npm install
```

## Run apps

```bash
npm run dev
```

This starts:
- customer app on http://localhost:5173
- admin app on http://localhost:5174
- backend on http://localhost:5001

## Production build

```bash
npm run build:customer
npm run build:admin
```
